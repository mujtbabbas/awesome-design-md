# Reader's Guide — awesome-design-md

## What this project is

**Awesome DESIGN.md** is a curated collection of **DESIGN.md files — written
design-language analyses of well-known developer-focused websites and
brands**. A DESIGN.md captures a site's design patterns, tokens and rules in
plain Markdown, so you can copy one into your own project, tell your AI agent
"build me a page that looks like this," and get UI that stays visually
consistent with that design language — with real design depth, not
surface-level imitation.

## How the content is organised

- `design-md/` — **the collection itself: 84 folders, one per site or brand**,
  each holding that site's DESIGN.md analysis. Examples visible in the tree
  include `airbnb`, `apple`, `airtable`, `binance`, `bmw`, `bugatti`,
  `claude`, `coinbase`, `cursor`, `elevenlabs`, `expo`, `ferrari`, `figma`,
  `framer`, `hashicorp`, `ibm`, `intercom` and `kraken`.
- [`README.md`](README.md) — explains **what a DESIGN.md is**, showcases the
  collection (with a live count badge), and links the entries.
- `CONTRIBUTING.md` — how new site analyses are added; `LICENSE` — MIT.

## How to use it

1. Browse `design-md/` for a site whose look you want to learn from or build
   in the style of.
2. Open its DESIGN.md and read the extracted patterns, tokens and rules.
3. To build with it: copy the DESIGN.md into your project and point your AI
   coding agent at it, as the README describes.
